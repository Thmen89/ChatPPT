# Layout For Each Slide
Also choose how each slide is laid out: set each slide's `layout` to the index of one of the layouts below.
- Let the slide's purpose decide: opening/closing → title layouts, processes/workflows → process layouts, comparisons → side-by-side layouts, data/metrics → chart layouts, concepts/ideas → image + text layouts, key insights → emphasis layouts.
- Vary layouts across the deck; adjacent slides should use different layouts unless the content needs the same one.
- Use a table of contents layout only for a slide that is a table of contents.
- Use a table or chart layout only when the slide has a table; charts need numeric data.
