# Configuration reference

Generated by `python -m chatppt --reference` (run in servers/fastapi); do not edit by hand.

ChatPPT reads `chatppt.toml` from the data directory (or `CHATPPT_CONFIG`). Every key can be set by environment variable instead: `CHATPPT_` + the key path upper-cased with `__` between levels. Environment wins over the file. Legacy Presenton variable names still work and log a warning.

| Key | Type | Default | Environment | Description |
|---|---|---|---|---|
| `server.public_url` | str | `'http://localhost:5000'` | `CHATPPT_SERVER__PUBLIC_URL` (legacy `NEXT_PUBLIC_URL`) | URL users open; used for links, CORS and the exporter. |
| `server.data_dir` | str | `'/data'` | `CHATPPT_SERVER__DATA_DIR` (legacy `APP_DATA_DIRECTORY`) | Where the database, uploads, exports, templates, prompts and this file live. |
| `server.database_url` | str |  | `CHATPPT_SERVER__DATABASE_URL` (legacy `DATABASE_URL`) | SQLAlchemy URL. Default is SQLite in data_dir; set postgresql://... to opt in. |
| `server.log_level` | str | `'info'` | `CHATPPT_SERVER__LOG_LEVEL` (legacy `LOG_LEVEL`) | debug, info, warning or error. |
| `server.error_reporting_dsn` | str |  | `CHATPPT_SERVER__ERROR_REPORTING_DSN` (legacy `SENTRY_DSN`) | Sentry-compatible DSN. Unset means no error reporting at all. |
| `llm.provider` | str |  | `CHATPPT_LLM__PROVIDER` (legacy `LLM`) | Default LLM provider id: openai, anthropic, google, vertex, azure, bedrock, openrouter, fireworks, together, cerebras, litellm, lmstudio, ollama, custom, codex. |

## Example

```toml
[server]
public_url = "https://decks.example.internal"   # TODO(owner): your URL

[llm]
provider = "openai"
model = "gpt-4.1"

[llm.providers.openai]
api_key = "sk-..."

[llm.providers.anthropic]
api_key = "sk-ant-..."

[llm.routing]
outline = { model = "gpt-4.1-mini" }                    # cheap and fast for the outline
content = { provider = "anthropic", model = "claude-sonnet-4-20250514" }

[images]
provider = "pexels"

[images.providers.pexels]
api_key = "..."

[features]
chat = true
memory = false

[defaults]
template = "general"
theme = "house"
n_slides = 10
```
